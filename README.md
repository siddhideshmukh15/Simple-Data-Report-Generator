# Simple Data Report Generator

A simple **Data Report Generator** built using Python. 
This beginner-friendly project takes numerical data from the user
and generates a basic report with total, average, highest, lowest,
and number of values.

## Features

- Accepts multiple values from the user
- Stores data using a list
- Calculates total
- Calculates average
- Finds the highest value
- Finds the lowest value
- Displays the number of values
- Generates a simple data report

## Technologies Used

- Python
- Lists
- `for` loop
- User input
- `sum()`
- `max()`
- `min()`
- Arithmetic operators
